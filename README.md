# Adobe2API

把 Adobe Firefly 账号接入常用生图客户端，集中管理账号、图片与使用记录。页面采用简约的白色界面，主要面向 Nano Banana 系列图片生成。

## 如何使用

1. 在项目目录执行 `docker compose up -d --build`。
2. 打开 [管理页面](http://localhost:8080)，首次访问设置管理员账号与密码。
3. 在账号池导入已登录 Adobe 页面中的生图请求内容，启用需要使用的账号。
4. 在设置页面创建访问密钥；需要返回公开图片链接时，填写外部可访问的服务地址。
5. 将客户端的服务地址设为你的 Adobe2API 地址，填入访问密钥，再选择可用模型开始生图。

OpenAI 客户端的地址通常填写 `http://你的服务地址:8080/v1`。Gemini 客户端使用同一服务地址，具体填写方式以客户端要求为准。完整调用示例见[接口使用说明](docs/protocol.md)。

服务更新后，账号、设置、日志和未清理的图片会继续保留。可通过 `docker compose logs -f` 查看启动情况，通过 `docker compose down` 停止服务。

## 功能介绍

- 支持可用的 Nano Banana 系列模型，以及文字生图和参考图生成。
- 提供 OpenAI 与 Gemini 兼容入口，支持图片链接与 Base64 返回。
- 集中管理多个 Adobe 账号、启用状态与登录刷新。
- 记录每次生成的耗时、参数、图片、参考图、积分与请求结果。
- 设置访问密钥、管理员账号密码、代理出口和公开图片地址。
- 按保留时间或占用空间清理图片，控制长期存储占用。

账号与模型的实际可用范围以 Adobe 页面和管理后台显示为准。服务会自动续期登录 Cookie 和访问令牌；Adobe 要求重新验证时，需要在已登录页面完成验证，再到账号池更新登录信息。仅导入 Cookie 不保证能够完成生图。

需要浏览器同步登录状态时，请使用不带账号密码的代理出口；带账号密码的代理可用于普通请求，但无法用于浏览器登录同步。
